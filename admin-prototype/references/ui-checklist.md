# 后台页面验收清单

新建页面检查实际包含的能力；迭代仅检查本次变化及受影响的交互、布局，不据此整改无关既有问题。不为清单添加演示功能或测试文件。

## 视觉

- 设计参数遵循当前项目 `design/system.json`；涉及主题或布局的修改，核对业务入口、离线文件与查看器嵌入效果一致。

- 在 1440×900 和 1920×1080 视口核对侧栏、标题、筛选卡、列表卡、分页与抽屉；涉及断点再看 1600px。
- 查询框与筛选操作紧凑一致，换行后仍可用；具体尺寸遵循[设计规范](admin-demo.md)，不在清单重复定义。
- 表格内部横向滚动，操作列固定且不透底；列宽符合内容密度，长文本能查看全文，金额、状态和空结果清楚。
- 长列表滚动内容区，分页位置稳定，切换容量立即生效。
- 详情标题无重复，标签和值对齐；长字段、彩色摘要和只读信息可读。
- 抽屉字段与分节间距一致，不叠加留白；错误提示、禁用态与底栏可见，滚动不遮挡操作，焦点和图标按钮名称可识别。

## 操作

- 查询、重置、页签、分页和统计范围一致；筛选变化后仍落在有效页。
- 列表到详情、关联对象返回、复制、折叠、更多菜单和确认操作都能闭环。
- 新增或编辑的校验、取消、重复打开及提交反馈不会残留上次状态。

## 交付

- 运行项目可用的检查与构建命令；新模板运行 `npm run format:check`。模板维护测试从技能仓库运行 `node --test admin-prototype/tests/*.test.mjs`。
- 离线 HTML 可直接打开，无 CDN、缺失资源或错误路由；独立评审页按登记模式显示。
- 发布源写入 `.published/<source-id>/`；同步更新 `nav.json`、`nav.js` 和说明 HTML，不改手动源文件，失败保留原发布结果。
- 分开报告：页面打开与异常检查；本次业务最短操作闭环（如修改、保存、重新打开核对）；查看器中目录、页面与说明对应检查。浏览器冒烟仅证明页面可打开。只报告实际执行的命令与操作，明确未覆盖项。
