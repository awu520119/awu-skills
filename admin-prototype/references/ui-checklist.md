# 后台页面验收清单

用于实现后检查实际页面；不要求为每一项增加测试文件。不存在的业务模块不为验收补造。

## 页面与视觉

- 在 1440×900、1920×1080 下核对；涉及断点时补看 1600px。使用实际视口截图，不把缩放图直接当 CSS 尺寸。
- 黑色侧栏展开 220px、收起 80px；选中项与路由一致，折叠不丢导航；标题、账号、分页可见。
- 主体左右 20px，卡内 16px，控件高 32px；正文 14/22，页面标题 18/24。无局部随意放大字号或圆角。
- 筛选换行后字段与操作组仍清楚；页面不被宽表撑开；金额与数量对齐、小数一致、长值有完整查看路径。
- 所有操作列固定右侧，横向滚动前后屏幕位置不变；更多图标使用主色，行内间距 16px；操作超过 3 项时编辑与删除在更多菜单内。
- 表格固定操作列不透底，横向滚动可到达最后一列；空结果、长名称、多个标签和长编号不会重叠。
- 抽屉宽度与内容匹配；标题和关闭固定，正文独立滚动，最后一项不被底栏遮挡。
- 详情字段标签同宽、值起点对齐；长编号换行不挤压标签，复制按钮不改变文字基线。
- 表单两列对齐，标签在上；错误自然撑高、没有多余空框。上传区、已选文件和删除状态都可见。

## 操作闭环

- 关键词 Enter/按钮查询、下拉筛选、重置与分页结果一致；改变筛选回到有效页。
- 列表到详情再返回保留上下文；复制、折叠日志、更多菜单不是空操作。
- 新增校验当前步骤；返回保留值；全量校验定位正确步骤。上游字段变更后下游清理。
- 提交后列表或详情反映修改；取消再打开无临时残留。草稿仅在存在真实恢复能力时显示。
- 连续打开不同记录、重复提交、空数据、无结果及边界输入均有合理反馈。
- 键盘可访问主要入口，焦点可见，弹层关闭后返回触发按钮；图标按钮有名称。

## 构建与可移植性

- 运行 `npm run check`、`npm run build`；涉及脚本时运行对应路径的实际命令。
- 使用技能目录内的规范、模板及资源，不依赖历史项目或个人机器绝对路径。
- 普通原型无需其他 skill；查看器是可选集成，未配置时照常构建和导出 HTML。
- 离线 HTML 不依赖 CDN、外部字体或相邻 dist 资源；用 file:// 打开检查真实渲染与控制台。
- 嵌入查看器的 `srcdoc` / Blob 页面应能初始化路由，导航可切换，无 URL 基址错误。
- 发布到查看器时保留业务侧栏、标题和页面内容，发布失败恢复原内容。
- 交付给用户可点击的 HTML/项目路径，简述已验证操作与实际限制，不把未执行检查写成通过。
