# 后台页面验收清单

新建检查页面实际包含的能力；迭代检查本次变化及受影响部分。按下面清单执行适用项，不为补齐清单添加业务功能。共享运行器用法见[浏览器验收](browser-check.md)。

## 视觉

- 在 1440×900、1920×1080 检查侧栏、标题、筛选卡、列表卡、分页与抽屉；涉及断点再看 1600px。样式与项目设计配置一致，筛选换行可用。
- 宽表在内部横向滚动，操作列固定且不透底；长文本可查看全文，金额、状态和空结果清楚。长列表滚动时分页稳定。
- 详情标题不重复、标签和值对齐；表单字段和分节不叠加留白，错误提示自然撑开，抽屉底栏不遮挡正文。关闭、键盘焦点返回和图标按钮名称可识别。

## 操作与交付

- 查询、重置、页签和统计范围一致；空结果正确，筛选回到有效页，切换容量立即更新。
- 本次涉及的详情、关联对象返回、复制、折叠、更多菜单和确认操作可用；编辑检查校验、取消、修改保存及重新打开，状态不残留。
- 最终离线文件可直接打开，无缺失资源、外链请求或错误路由。实际打开截图审阅；自动断言不替代视觉判断。修复后重新导出和检查，不沿用旧产物的报告。
- 本次涉及查看器时，另查嵌入布局、目录入口和对应说明。交付分别说明页面打开、业务闭环、查看器检查的结果及未执行项。
