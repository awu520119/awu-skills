# 后台页面验收清单

只检查页面实际包含的能力；不为清单添加演示功能或测试文件。

## 视觉

- 在 1440×900 和 1920×1080 视口核对侧栏、标题、筛选卡、列表卡、分页与抽屉；涉及断点再看 1600px。
- 查询输入框使用 280×32px 紧凑规格、2px 圆角；右侧 40px 主色按钮与输入框紧贴，搜索图标为白色，提示语写明范围；筛选换行后操作组仍可用。
- 表格内部横向滚动，操作列固定且背景不透底；列宽与内容密度匹配，单项/双项/更多操作列分别不出现过大留白，长文本或操作内容列有合理最大宽度、两行截断与完整内容悬浮提示；金额、状态和空结果都能完整辨认。
- 长列表只滚动表格内容区，分页固定在列表卡底部；数据多少变化、切换页码或每页条数时，分页位置稳定且新容量立即生效。
- 详情没有重复大标题；标签同宽且文字两端对齐，值起点一致，长字段可读。抽屉正文与底栏互不遮挡；彩色摘要文字有足够对比度。
- 只读详情核对首节顶部、标题到字段、字段行之间及分节之间四种间距；不得由 section padding、标题 margin 和字段 padding 重复叠加造成局部稀疏。
- 表单抽屉正文上/左右/下内边距为 16/24/24px；分节标题与字段、字段与字段之间的间距节奏一致，不同时叠加相邻字段的上下 margin；字段、错误、禁用态和底部按钮对齐，焦点可见，图标按钮有名称。
- 有底部操作栏时，确认它固定吸底、白色背景、顶部有分隔线和上方阴影，滚动正文不会被操作栏遮挡。

## 操作

- 查询、重置、页签、分页和统计范围一致；筛选变化后仍落在有效页。
- 列表到详情、关联对象返回、复制、折叠、更多菜单和确认操作都能闭环。
- 新增或编辑的校验、取消、重复打开及提交反馈不会残留上次状态。

## 交付

- 运行项目可用的检查与构建命令；新模板还运行 `npm run format:check` 和 `npm test`。
- 离线 HTML 可直接打开，无 CDN、缺失资源或错误路由；独立评审页按登记模式显示。
- 发布到查看器时，只写受控 `.published/<source-id>/`；失败保留原发布结果。报告实际验证命令和未覆盖项。
