# 发布到原型查看器的 PRD 内容建议

`desc/<id>.md` 是查看器右侧展示的页面说明。它不是源码注释，应让产品、设计和开发能从页面行为回溯需求。

## 最小结构

```md
# <页面标题>

## 页面目的
说明使用角色、业务问题和页面价值。

## 交互说明
说明入口、主要操作、页面跳转、抽屉/弹窗、加载/空态/成功反馈，以及 Demo 当前已实现的状态。

## 业务规则
说明字段含义、默认值、校验、权限、筛选/排序/分页口径。未知规则标记为“待确认”，不要臆造。

## 异常情况
说明网络失败、无数据、重复提交、无权限、边界值和恢复方式。
```

## 完整 PRD 可补充

- 需求背景与目标
- 范围：本次包含 / 不包含
- 页面字段与操作清单
- 验收标准和测试用例
- 数据依赖、埋点、非功能要求
- 上线、灰度与回滚计划

在描述中使用明确标签：`Demo 已实现`、`原型展示`、`PRD 约定`、`待确认`。静态 Mock 数据、按钮反馈和前端路由不应被表述为真实后端能力。
