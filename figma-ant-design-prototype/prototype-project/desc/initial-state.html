初始化状态模板

页面目的

为新建的 prototype-design 项目提供一个可立即查看的初始页面，帮助团队确认页面容器、左侧导航、中心内容区和右侧 PRD 展示区已经连通。

交互说明

  • Demo 已实现：展示顶部栏、左侧导航、面包屑和初始化空态。
  • 原型展示：页面中心提供“创建页面”和“查看使用说明”两个视觉按钮。
  • Demo 已实现：按钮为静态展示，不触发跳转、不写入数据。
  • 待确认：后续页面创建流程、权限和数据来源由具体业务 PRD 约定。

业务规则

  • PRD 约定：新项目首次打开时默认展示本页面。
  • PRD 约定：当项目已有业务页面时，应将本页面作为模板替换或移除。
  • 待确认：是否保留初始化页面作为帮助入口。

异常情况

  • 原型展示：当前页面无网络请求，不包含加载失败、无权限或提交失败状态。
  • 待确认：真实页面接入后补充空数据、接口失败和重复提交的恢复方式。

验收标准

  1. 页面可通过 prototype-design 查看器打开。
  2. 页面入口标题为“初始化状态模板”。
  3. 页面与本 PRD 使用同一发布 id：initial-state。
  4. 页面在无额外图片、字体和第三方依赖的情况下可直接预览。
