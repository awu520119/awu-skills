# HTML + PRD 发布到原型查看器操作手册

本手册用于将当前目录中的 HTML 页面和 PRD 文件发布到独立的原型查看器中。

## 一、准备文件

确保当前目录中存在以下文件：

```text
xiaomifeng-share.html
xiaomifeng-share.md
```

其中：

- `xiaomifeng-share.html`：需要预览的页面
- `xiaomifeng-share.md`：对应的产品需求文档

## 二、首次发布

打开终端，进入当前项目目录：

```bash
cd /Users/awu/Desktop/assets/原型设计规范/figma-ant-design-prototype
```

执行发布命令：

```bash
python3 scripts/publish_demo.py \
  ./prototype-project \
  --init \
  --source ./xiaomifeng-share.html \
  --prd ./xiaomifeng-share.md \
  --id xiaomifeng-share \
  --title "小米风分享页"
```

命令会自动创建 `prototype-project` 原型项目，并将 HTML 和 PRD 放入其中。

## 三、启动原型查看器

发布成功后执行：

```bash
python3 scripts/preview.py \
  ./prototype-project \
  --node xiaomifeng-share \
  --open
```

浏览器会自动打开原型查看器：

- 左侧：页面导航
- 中间：HTML 页面预览
- 右侧：PRD 文档预览

如果浏览器没有自动打开，可复制终端显示的 `http://127.0.0.1:4173/` 地址到浏览器中访问。

## 四、更新已有页面

修改 `xiaomifeng-share.html` 或 `xiaomifeng-share.md` 后，重新发布时增加 `--replace`：

```bash
python3 scripts/publish_demo.py \
  ./prototype-project \
  --source ./xiaomifeng-share.html \
  --prd ./xiaomifeng-share.md \
  --id xiaomifeng-share \
  --title "小米风分享页" \
  --replace
```

然后重新启动预览：

```bash
python3 scripts/preview.py \
  ./prototype-project \
  --node xiaomifeng-share \
  --open
```

## 五、常见情况

### HTML 依赖图片、CSS 或 JS

如果 HTML 依赖同目录资源，应将资源放在一个目录中，并传入目录：

```text
my-demo/
├── index.html
├── style.css
├── app.js
└── images/
```

发布命令：

```bash
python3 scripts/publish_demo.py \
  ./prototype-project \
  --source ./my-demo \
  --prd ./my-demo.md \
  --id my-demo \
  --title "我的页面"
```

### 停止预览服务

在运行预览服务的终端按：

```text
Ctrl + C
```

### 查看生成结果

发布后主要文件位于：

```text
prototype-project/
├── index.html                         # 原型查看器
├── nav.json                           # 页面导航
├── pages/xiaomifeng-share/index.html  # HTML 页面
└── desc/xiaomifeng-share.html         # 渲染后的 PRD
```

本 Skill 自带原型查看器和基础 Markdown 渲染，不依赖其他项目或 Skill。
